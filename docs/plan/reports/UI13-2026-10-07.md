A thin divider and endpoint dot now sit inside the relevant turn, followed by a direct sentence such as “Both agents reached this turn.” A short catalogue-backed guide under Conversation explains that an agent can have a turn even when its chat does not show it. ## Review challenge

Root review found that a filtered receipt could be positioned above an earlier visible turn and look attached to it. The connector was removed and the hidden position was made a separate summary. Root also removed a redundant heading from visible endpoints after inspecting the live view.

The independent reviewer found three related issues. First, “every earlier turn” was false after a merge skipped an earlier turn. Second, “Who has this turn” looked like an exhaustive list even though the marker lists only sides whose receipt ends there; “latest agent turn” was also false when a later local turn follows a waiting turn. All marker copy now describes a reached position in the combined conversation without making those claims, and a note test guards against the overstatement. Third, the first render used a Pinned filter, so it did not show both separate endpoints; the test now unfolds All and renders separate, hidden and shared states in each theme. The reviewer rechecked the focused delta and found no remaining blocker.

## Decision and gap

R10 in the protected sync-status spec describes an agent as having everything above its marker. A keep-side merge can leave a `skipped` turn above a later reached point, so that sentence is not always true. UI13 uses truthful reached-position copy and records the spec clarification as a question in STATUS.md. C2/E12 must generate the new guide and receipt wording rather than restoring older fixture text.

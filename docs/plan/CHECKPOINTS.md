### CP5 checklist
- [ ] Link, by each of the three ways, between every pair of the four tools.
- [ ] Copy without linking, each tool to each tool, with the right relaunch note.
- [ ] A turn written on each side reaches the other: closed chat, open chat, replying chat.
- [ ] Both sides ahead: merge by time, one side first, don't reorder, keep one side, split.
- [ ] Undo on each tool, then restore.
- [ ] Limit reached on Claude and on Codex: the offer, and "available again".
- [ ] Brief by agent, and with the writer unavailable.
- [ ] Second opinion, and add it to the chat.
- [ ] Setup with each finding, and its fix.
- [ ] A format version Baton does not know: writing off, reading and attaching on.
- [ ] Every row of the notes table seen on screen at least once.

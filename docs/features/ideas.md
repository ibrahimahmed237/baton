# Ideas beyond the first version

Not agreed, not planned. Each is here so it can be picked, changed or dropped.

Six ideas that started here are now in the first version and specified in [working-across.md](working-across.md): the switch offer when a tool hits its limit, how full each side is, "since you left", second opinion, keeping a turn on one side, and pinning turns.

## Still ideas

**1. A note for the other agent.** When pressing Continue, the user can type one line ("pick up at the failing test in auth"). It goes across as the first thing the other agent reads.

**2. Same instructions for both agents.** Claude reads `CLAUDE.md`, Codex reads `AGENTS.md`. Baton can show when they differ and offer to make one point at the other, so both agents follow the same project rules.

**3. Folder and branch check.** Warn when the two linked chats work in different folders or on different git branches. (Listed in link-actions.md as later.)

**4. Check a link.** Re-read both chats against Baton's record and report or repair anything that does not match. (Listed in link-actions.md as later.)

**5. Search across both tools.** One search box over every chat in Claude and Codex, linked or not.

**6. Save a conversation as a file.** (Listed in link-actions.md as later.)

**7. Notifications for long waits.** (Listed in sync-status.md as later.)

**8. More agents.** Shape the engine so a third tool, such as Gemini CLI or Cursor, can be added as another side. Links would stay one to one.
